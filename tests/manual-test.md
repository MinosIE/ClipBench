# ClipBench 手工测试清单

自动测试覆盖后端接口与核心流程（`pytest tests/`），本清单用于**浏览器端 UI / 交互**的回归验证。
执行方式：`./start.sh` 后打开 `http://localhost:8080`，按模块逐项勾选。

## 测试素材准备

- 一段 ≥ 60s、带音频的 mp4（建议 720p+，含字幕区域，用于去字幕/压缩/裁剪等）
- 一段 HEVC/H.265 编码的视频（用于验证 HEVC 智能压缩路径）
- 一张透明 PNG 水印图（`logo.png`）
- 一段竖版视频（9:16，用于验证 9:16 裁剪预设）

---

## 0. 全局 / 通用

- [ ] 页面在暗色主题下打开正常，Tab 图标与文字完整显示
- [ ] 上传 mp4 后，右侧媒体信息卡片展示：文件名、大小、时长、分辨率、帧率、码率
- [ ] **编码信息**：视频编码显示编码标签（如 `H.264 (h264)` / `HEVC (hevc)`），HEVC 源能明确看出
- [ ] 上传 .exe / .txt 被拒绝并提示"不支持的文件类型"
- [ ] 同文件重复上传自动改名（`_1` 后缀）
- [ ] 文件卡片删除按钮可删除文件，列表同步刷新
- [ ] 任务区：任务开始后进度条平滑增长（SSE 实时推送，无需刷新页面）
- [ ] 任务完成后可下载输出文件；可取消运行中的任务；可删除任务并清理输出
- [ ] 服务重启后：已完成任务保留在任务列表，残留 running 任务被标记为 cancelled（孤儿巡检）

## 1. 去字幕

- [ ] 4 种模式均可选择：边缘修复 / 模糊 / 马赛克 / 内容感知修复
- [ ] 默认区域为底部 1/3；可手动调整顶部/底部高度
- [ ] 边缘修复（delogo）：字幕区域被去除，画面边缘平滑过渡
- [ ] 模糊 / 马赛克：区域被对应效果覆盖
- [ ] 内容感知修复（inpaint）：效果最接近无痕；同时运行多个去字幕任务时，inpaint 任务显示 `queued` 排队
- [ ] 处理后音频不受影响，时长一致

## 2. 拆分

- [ ] 按时长模式：输入每段时长（如 30s），输出多个分片文件
- [ ] 按片段模式：支持时间轴输入 `00:00:00` 格式与纯秒数；多片段同时导出
- [ ] 非法片段校验：开始 > 结束、开始为负、超过总时长 → 明确报错
- [ ] 输出 GIF：调色板优化，GIF 可播放
- [ ] 静音选项：开启后输出无音轨

## 3. 截图

- [ ] 单帧模式：指定时间点截取一帧，输出 jpg/png 可下载
- [ ] 间隔模式：按间隔（如 5s）批量截帧，输出到目录
- [ ] 间隔为 0 或负数 → 报错"间隔需大于0"
- [ ] 缩略图：文件卡片上的首帧缩略图正常显示

## 4. 格式转换

- [ ] mp4 → mkv / webm / avi / gif 等常见格式均可转换
- [ ] 转 GIF / webm 自动重编码（webm 为 VP9）
- [ ] 重编码开关 + CRF 滑条生效（进度数值跟随滑条变化）
- [ ] 音频开关：关闭后输出无音轨
- [ ] 快速启动（faststart）开关：开启后输出文件 moov 前置，浏览器可边下边播
- [ ] 输出格式与源格式相同 → 有提示或合理行为，不产生无意义转码

## 5. 压缩

- [ ] **H.264 源**：走 `libx264` 重编码，文件变小、画质可接受
- [ ] **HEVC 源**：走 `libx265`，任务名/日志标明 HEVC；不因强转 H.264 而变大
- [ ] 低码率源（< 2Mbps）压缩时 CRF 自动加大偏移，避免文件反增
- [ ] 分辨率缩放：720p / 480p / 360p 生效，长宽比保持
- [ ] CRF 滑条（17–28）数值实时显示；faststart 开关生效
- [ ] 压缩后视频可正常播放，音频保留

## 6. 裁剪

- [ ] 预览图加载正常，拖拽/输入选区后显示裁剪框
- [ ] 固定尺寸预设 16:9 / 9:16 / 1:1 / 4:3 生效
- [ ] "清除选区"按钮可重置选区（次要按钮样式）
- [ ] 输出为源同格式，裁剪区域准确，无黑边

## 7. 合并

- [ ] 选择 2 个及以上文件后"合并"按钮可用；少于 2 个提示"请至少选择 2 个文件"
- [ ] 合并后总时长为各部分之和，音画同步（内部统一重编码 h264+aac）
- [ ] 选择顺序决定输出顺序（可排序）

## 8. 旋转 / 翻转

- [ ] 90° / 180° / 270° 旋转 + 水平/垂直翻转可组合，预览图方向正确
- [ ] 不选任何操作直接提交 → 提示"请选择旋转或翻转操作"
- [ ] 输出分辨率随旋转正确交换（竖版 ↔ 横版）

## 9. 水印

- [ ] 文字水印：字号、颜色、透明度可调，5 个位置（4 角 + 居中）均正确
- [ ] 图片水印：上传透明 PNG 后可选缩放、透明度、位置；watermark_id 正确关联
- [ ] 图片水印未先上传图片 → 提示"请先上传水印图片"
- [ ] 水印不遮挡关键内容，输出可下载

## 10. 调速 / 倒放

- [ ] 速度滑条 0.5x–4x，数值徽标实时显示
- [ ] 0.5x（慢放）与 2x（快放）音调正常（atempo 链处理 >2x）
- [ ] 倒放开关：视频与音频同时倒放，播放正常
- [ ] 速度 ≤ 0 → 报错"速度需大于 0"

## 回归验证（改代码后必测）

- [ ] `pnpm build` 无错误；后端能托管 `dist/` 最新构建（页面显示新 bundle）
- [ ] `python -m pytest tests/ -v` 全绿（见 README「测试」章节）
- [ ] 上传/下载大文件（>1GB）时进度正常，无内存异常
- [ ] 路径安全：浏览器地址栏直接访问 `/media/../tasks.json` 等被拒绝（404）
