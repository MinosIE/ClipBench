# ClipBench UI 设计文档

记录 ClipBench 前端（SolidJS + Vite）的界面布局体系、设计 Token 与各功能页（Tab）的布局规范。
随迭代更新；样式全部集中在 `src/styles.css`，组件在 `src/components/panels/` 与各顶层组件。

---

## 1. 整体框架

应用为**单页应用（无路由）**，顶部标题栏 + 主体两栏：

```
┌──────────────────────────────────────────────────────────────┐
│  标题栏（应用名 + 主题）                                       │  60px
├───────────────┬──────────────────────────────────────────────┤
│  左侧栏        │  主区（根据选中 Tab 渲染面板）                │
│  - 文件上传    │  ┌─ 左侧：功能面板（每个 Tab 一个） ──────┐   │
│  - 文件列表    │  │                                        │   │
│  - 任务列表    │  └────────────────────────────────────────┘   │
│  (400px)      │  ┌─ 右侧：Tasks 任务面板 ────────────────┐   │
│               │  │  任务卡片 / 压缩对比 / 进度           │   │
└───────────────┴──┴────────────────────────────────────────┘   │
```

- 主体用 flex 横向排列：`左侧栏` + `主区`。
- 主区内部再用 flex 横向排列：`主功能面板（.main-left）` + `任务面板（.tasks-pane, 400px）`。
- 未选择媒体文件时，主区显示居中 `.empty-state`，不渲染左右子面板。

**布局间距（全局收紧版）：**

| 变量 / 类 | 值 | 说明 |
| --- | --- | --- |
| `.layout` padding / gap | 14px | 顶层外边距与列间距 |
| `.main` / `.main-left` gap | 14px | 主区与功能列间距 |
| `.tab-panel` padding | 18px 22px | 功能面板内边距 |
| `.tasks-pane` 宽度 | 400px | 右侧任务列宽 |
| `.actions` margin-top | 14px | 提交按钮区上间距 |

## 2. 设计 Token

### 2.1 配色（暗色主题，CSS 变量）

| 变量 | 用途 |
| --- | --- |
| `--panel` | 主面板背景（卡片主体） |
| `--panel-2` | 次级背景（form-card、aside 浅卡、输入框底） |
| `--border` | 边框线 |
| `--text` | 主文字 |
| `--muted` | 次要文字 / 说明 |
| `--accent` | 主题强调色（按钮、激活态、链接） |
| `--accent-soft` | 强调色浅底（建议条渐变） |
| `--ok` | 正向/绿色（压缩节省） |
| `--danger` | 危险/红色（体积增大、删除按钮） |
| `--radius` | 圆角基准 |

> 具体取值见 `src/styles.css` 的 `:root` 定义。

### 2.2 间距与圆角基准

- 圆角：`--radius`（面板/卡片）、`10~12px`（内部小卡、按钮区）。
- 字段间距：`.field` margin-bottom `12px`；`.row` `10px`。
- 表单卡片：`.form-card` padding `14px 16px`；内部 `.grid2` 列间距 `14px`。
- 按钮：主按钮 `.btn`（强调色填充）、`.btn.secondary`（描边）、`.btn.danger`（红）、`.btn.small`（紧凑）。

### 2.3 字体

- 正文 / 标签：`12.5~13px`（标签 13px，说明 12px）。
- 行高：说明文案 `1.6~1.7`，密集信息优先单行。

## 3. 三种布局模板

所有功能面板（`.tab-panel`）共用一套布局语言，按内容形态归为三类。

### 模板 A：工作台双栏（左视频 + 右参数）

用于**需要可视化预览**的功能：**去字幕、裁剪**。

```
.tab-panel
└── .workbench            // grid: 视频列 | 参数列
    ├── 左列：视频 / 画布 + 提示
    └── 右列：.region-tools（参数 + 操作说明 + 按钮）
```

- 去字幕：`.workbench` `grid-template-columns: 1.5fr 1fr`（左大右小）。
- 裁剪：`.workbench.crop-wb` `1.8fr 1fr`（参数更少，视频更宽）。
- 左列放 `<video>` 或带选区层（`.video-wrap` 相对定位，选区 `absolute` 叠加）。
- 右列 `.region-tools`：竖向排列 `field` + `.seg` + `.actions` + 紧凑 `hint`。

### 模板 B：左表单卡 + 右贴士卡（同排并排）

用于**纯参数表单**功能：**压缩、拆分、截图、旋转、调速、格式转换、水印、合并**。

```
.tab-panel.two-col         // grid: minmax(0,1fr) | 248px; align-items: stretch
├── h2 / p.muted          // 标题 + 副标题（跨整行 grid-column:1/-1）
├── .suggestion-bar?      // 智能建议条（仅压缩，跨整行）
├── .form-card            // 主操作卡（占左列 1/2）
│   └── 内部单列堆叠（外层已左右分栏，不再内嵌 grid2）
├── aside.panel-aside     // 贴士卡（占右列，与 form-card 同排并排、等高）
└── .actions              // 提交按钮（跨整行，置于 aside 之后）
```

要点：
- **左右并排而非上下**：`.form-card` 占左列（`grid-column: 1/2`），`aside.panel-aside` 自动落右列，**两者同一行左右并排**；`align-items: stretch` 让两卡等高，左卡不再有下方空白。
- **DOM 顺序约束**：`.actions` 必须放在 `aside` **之后**。因为 `.actions` 跨整行（`grid-column: 1/-1`），若它插在 `form-card` 与 `aside` 之间，会把 `aside` 挤到按钮下方的左列，破坏并排。正确顺序为 `form-card → aside → actions`。
- **外层已分栏，内部不再两列**：`form-card` 内部改为单列紧凑堆叠（之前曾在内部用 `.grid2` 两列，外部分栏后再两列会过窄）。压缩因字段较多仍保留内部 `.grid2.compact`（CRF / 分辨率两列），在外层左列 1fr 宽度下仍合适。
- 模式选择类 `.seg`、`.row`、`.range-row`、`.check-row`、`.field.col-span`、`.hint.col-span` 在内部单列下自然占满。
- 短数字/文本输入在 `.grid2.compact` 内限宽 `max-width: 220px`，避免被拉太长。
- 右侧 `aside.panel-aside`（248px，sticky）：`<h4>` 标题 + `<ul>` 贴士 + `.aside-note` 高亮提示。

### 模板 C：网格表单（密集）

合并的素材选择本身就是密集网格（`pick-grid` 缩略图墙），填在左列 `form-card` 内；右侧同为合并贴士卡（模板 B 的左右并排布局），无右侧留白问题。

## 4. 各 Tab 布局速查

| Tab | 模板 | 左/主区关键元素 | 右侧 |
| --- | --- | --- | --- |
| 去字幕 | A 工作台 | 视频 + 选区层 + 时间轴 | 模式/区域/按钮 + 说明 |
| 裁剪 | A 工作台 | 视频 + 拖拽选区 | 当前选区 / 常用比例 / 按钮 |
| 压缩 | B 左表单+右贴士 | 建议条 → 编码 seg → 预设 seg →（CRF|分辨率）两列 | 压缩贴士（右列） |
| 拆分 | B 左表单+右贴士 | 方式 seg → 时长/输出 → GIF 参数 → 区间列表（单列堆叠） | 拆分贴士（右列） |
| 截图 | B 左表单+右贴士 | 模式 seg → 时间/格式（单列堆叠） | 截图贴士（右列） |
| 旋转 | B 左表单+右贴士 | 角度 seg → 翻转勾选 → 说明行（单列堆叠） | 旋转贴士（右列） |
| 调速 | B 左表单+右贴士 | 速度 seg → 倍率/range → 倒放勾 → 说明行 | 调速贴士（右列） |
| 格式转换 | B 左表单+右贴士 | 目标格式 seg → 编码器/CRF → 音频/快启勾 | 转换贴士（右列） |
| 水印 | B 左表单+右贴士 | 类型 seg → 内容 → 位置 seg → 边距/透明度 | 水印贴士（右列） |
| 合并 | B 左表单+右贴士 | pick-grid 缩略图墙 + 顺序列表（左列） | 合并贴士（右列） |

## 5. 组件规范

### 5.1 表单控件

- **`.seg`**（分段选择器）：一组 `.btn` 风格的互斥按钮，激活态 `.active` 用 `--accent`；用于模式、编码、分辨率、位置等离散选择。
- **`.range-row`**：`input[type=range]` + `.range-val`（实时数值）。
- **`.check-row`**：checkbox + 文字，内联图标定位（左侧 30px 留位）。
- **`.field`**：`label` + 控件 + 可选 `.hint`，垂直排列。
- **`.form-card`**：浅色圆角卡片，把参数区与标题/按钮分层。

### 5.2 智能建议条（压缩专用）

`.suggestion-bar`：左侧强调色竖条 + 渐变浅底，内联展示 `源编码 / 质量 CRF / 预估↓60%` 等标签 + 一句话 `summary` + 「一键应用」按钮。加载态显示"正在分析…"。数据来自后端 `/api/compress_suggest`（非前端写死）。

### 5.3 任务卡片（右侧 Tasks）

- 基础：图标 + 名称 + 状态徽章 + 进度条 + 耗时 + 下载/删除。
- **压缩对比**（`compress-compare`）：源 → 输出 的 大小 / 编码 / 分辨率 / 节省% 对照；节省为正绿色 `--ok`，体积增大红色 `--danger`。
- **源文件提示**：`task-src` 显示「源：xxx.mp4」。

### 5.4 空状态

- 未选文件：主区居中 `.empty-state`（大图标 + 提示文案）。
- 面板内未选：`.empty`（"请先在左侧选择媒体文件"），在 `two-col` 下跨整行。

## 6. 响应式

- 窄屏断点（≤1000px）：`.tab-panel.two-col` 退化为单列（`1fr`），`form-card.grid2` 退化为单列，`.panel-aside` 变为静态（不再 sticky）；`.workbench` 退化为上下堆叠（视频在上，参数在下）。
- 顶层 `.layout` 始终保持横向，但列宽随视口收缩；左侧栏最小宽度受内容约束。

---

## 7. 设计原则（本次迭代确立）

1. **高空间利用率**：纯表单面板采用「左表单卡 + 右贴士卡」同排并排（`.form-card` 占左列、`aside.panel-aside` 占右列、`align-items: stretch` 等高），杜绝竖排长条留白与表单下方空白。
2. **紧凑间距**：全局收紧 padding/margin（见 §1、§2.2），信息密度优先，不堆空白。
3. **主操作区与说明分层**：参数收进 `.form-card`，实用贴士收进右侧 `aside`，互不干扰且左右并排。
4. **可视化功能双栏化**：去字幕、裁剪采用「左预览 + 右参数」工作台布局，操作所见即所得。
5. **后端驱动智能**：智能建议、编码推断等均由后端计算，前端只渲染，避免写死常量。
6. **一致性**：所有 Tab 复用同一套 `.seg / .field / .form-card / .panel-aside / .actions` 组件与间距规范；双栏面板统一 DOM 顺序 `form-card → aside → actions`。
