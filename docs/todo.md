# Todo — 功能设计建议

> 基于当前功能设计（10 个处理功能 + 左侧文件栏 / 中间功能面板 / 右侧任务栏）提出的改进方向。
> 按优先级排列，勾选表示已完成。

## P0 — 任务闭环（性价比最高）

- [x] ~~**任务产物可打开 / 下载**~~（已评估：不需要。产物路径与查看/下载入口已具备）
- [x] **失败任务可查看 ffmpeg 日志**（2026-08-26 完成）
  - 后端 `_run_ffmpeg_locked` 将 ffmpeg 输出（stderr 并入 stdout）存入 `task["log"]`（尾部 600 行内截断）。
  - 前端失败任务卡片新增「日志」按钮，弹窗（深色 `<pre>`，可滚动）展示完整日志。
  - 涉及：`app.py`、`Tasks.tsx`、`api.ts`、`styles.css`。
- [x] **处理中可取消**（2026-08-26 完成，实为修复）
  - 现状：前端「取消」按钮已存在，但 `cancelTask` 请求了复数路径 `/api/tasks/<id>/cancel`，后端只有单数 `/api/task/<id>/cancel`，一直 404 失效。
  - 修复：`api.ts` 改为单数路径；`onCancel` 加错误兜底 toast。
  - 涉及：`api.ts`、`Tasks.tsx`。

## P1 — 批量与效率

- [ ] **批量操作（应用到全部选中）**
  - 现状：除合并外均为单文件操作。
  - 建议：选中多个文件时功能面板出现「应用到全部选中」，逐个入队。
  - 涉及：各功能 Panel、`store.ts`（选中集已存在）。
- [x] **时间点输入体验优化**（2026-08-26 完成）
  - 现状：拆分/截图时间点为纯文本输入（裁剪为画布选区，无时间输入）。
  - 方案：新增复用组件 `src/components/TimePickerModal.tsx` —— `<video>` 播放/拖进度预览目标画面，点按钮把当前时间格式化为 HH:MM:SS 填入输入框；浏览器无法解码的编码提示手动输入。
  - 接入点：拆分「时间区间」每行加「预览」按钮（设为起点/终点）；截图「单张」时间点旁加「预览取帧」按钮（使用当前时间）。
  - 涉及：`SplitPanel`、`ScreenshotPanel`、`TimePickerModal.tsx`（新增）、`styles.css`。
- [ ] **输出目录管理**
  - 现状：产物堆在同一目录，无「输出」视图。
  - 建议：增加输出文件列表（大小/时间/清理），或任务内直接展示产物路径。
  - 涉及：`app.py`（输出目录扫描/清理接口）、新增输出视图或并入 `Tasks.tsx`。

## P2 — 锦上添花

- [ ] **任务重试**
  - 建议：失败任务一键「重试」（带原参数），省去重新填表单。
  - 涉及：`Tasks.tsx`、`store.ts`（task 记录已有参数）、各 Panel 提交逻辑复用。
